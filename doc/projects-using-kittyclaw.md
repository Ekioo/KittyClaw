# Projects using KittyClaw

KittyClaw can coordinate work in any Git-backed project. This page lists public projects whose maintainers or community members report using KittyClaw.

Inclusion is informational, not an endorsement. Each project remains owned, maintained, and licensed by its respective authors.

## Verification labels

- **Verified workspace** — the public repository contains KittyClaw workspace markers, such as `.agents/` configuration or a reference to the KittyClaw API.
- **Community-reported** — KittyClaw usage was reported by a maintainer or community member, but the public repository does not expose enough metadata to verify it. Keeping orchestration files private or untracked is perfectly valid.

## Public projects

### [KEA](https://github.com/mokbhai/KEA)

**Verified workspace**

A cross-platform AI utility for rewriting, dictation, meeting notes, and text-to-speech, built with Tauri, Rust, and React. Its public repository includes a KittyClaw `.agents` workspace and API preamble.

### [Claw](https://github.com/OGbikram0001/Claw)

**Community-reported**

A public repository reported as being developed with KittyClaw. Its current public README does not yet describe the product or expose KittyClaw workspace metadata.

## Add your project

Using KittyClaw on a public project? Open an issue or pull request with:

- the repository URL;
- a short, plain-language description;
- an optional screenshot or demo link;
- whether the repository publicly exposes its KittyClaw workspace configuration.

Projects can be listed without publishing `.agents/`, memories, secrets, run logs, or any other private orchestration data.
